ASSETS

js13kGames 2026 requires that the entrant holds the rights to every asset.
PRISMHORN holds them by construction: it ships NO asset files at all.

  · Every pixel of art is drawn at runtime by g.js — the valley, the aurora,
    the unicorn, the seven bands, the blooms, the blight, the cairns and the
    geodes. There is no image file anywhere in the package.
  · Every sound is synthesised at runtime through the Web Audio API from
    oscillators declared in g.js. There is no audio file anywhere in the
    package, and no third-party audio library is vendored or fetched.
  · There are no external resources of any kind (js13kGames rule II): no CDN,
    no web fonts, no analytics, no network calls. The two files in this
    package are the whole game.

Type faces are named generically (`ui-monospace, Menlo, Consolas, monospace`)
and resolved by the player's own operating system, so no font is embedded or
redistributed.
